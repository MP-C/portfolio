      ☁️ Google Drive

      Guarde e abra o seu Excel diretamente na sua conta Google. A aplicação só vê os ficheiros que ela própria criou.

      Como obter o Client ID (uma só vez)
      1. Em console.cloud.google.com crie um projeto.
      2. APIs e serviços → Biblioteca → ative a Google Drive API.
      3. Ecrã de consentimento OAuth → Externo → adicione o seu e-mail como utilizador de teste.
      4. Credenciais → Criar credenciais → ID de cliente OAuth → Aplicação Web.
      5. Em «Origens JavaScript autorizadas» coloque o endereço onde esta página está alojada (ex.: https://o-seu-user.github.io).
      6. Copie o Client ID para o campo acima.

      Não funciona se abrir o ficheiro diretamente do computador (file://). Precisa de https ou http://localhost.
